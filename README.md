# SmartSpoon 🍽️

SmartSpoon is an AI-powered recipe and meal planning web app that helps users cook smarter with available ingredients. It suggests recipes, gives nutrition estimates, supports health filters, voice input, leftover rescue mode, and personalized weekly meal plans.

## Features
- 🍲 Recipe suggestions from available ingredients
- 🎤 Voice input support
- 🥗 Health mode (diabetic, gym, weight loss, etc.)
- ♻️ Leftover rescue mode
- 📊 Match percentage & missing ingredients
- 📅 Personalized weekly meal planner
- ✨ Attractive responsive UI

## Tech Stack
- Python (Flask)
- HTML
- CSS
- JavaScript
- TheMealDB API
